About me

Engineer with an analyst's mindset

I'm Smruthi Ranjan Pradhan, a software engineer with a strong academic foundation an MCA (8.18 CGPA) from Pooja Bhagavat Memorial Mahajana PG Center and a BCA (7.94 CGPA) from St. Philomena's College, Mysuru.

I build with Python, Java and C, and use Django for web applications. My projects include an Emergency Assistance Android App, Deepfake Audio Detection in Python and Mask Detection using CNN. I back them with certifications in Data Science, IoT, Technical Consulting and Zoho SalesIQ.

Through internships at Excelsoft Technologies, Tekvocation and OctaNet, I've worked on real products and learned to pair clean engineering with business insight — from databases and analytics to UI/UX.
